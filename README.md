# MerkaBot (ربات فروشگاهی VPN برای 3x-ui)

یک ربات تلگرامی پیشرفته و کامل برای فروش و مدیریت سرویس‌های VPN (وی پی ان) که به طور مستقیم و یکپارچه به پنل [3x-ui](https://github.com/MHSanaei/3x-ui) متصل می‌شود.
## ✨ امکانات و قابلیت‌ها
- 🛒 **خرید سرویس**: مشاهده پلن‌ها و خرید سرویس جدید توسط کاربران به صورت تعاملی.
- 💳 **پرداخت کارت به کارت**: ارایه شماره کارت برای پرداخت‌های ریالی و ثبت فیش واریزی در انتظار تایید ادمین.
- 🚀 **ساخت خودکار کانفیگ**: اتصال به API پنل `3x-ui` جهت ایجاد و تخصیص کد کاربری بلافاصله پس از تایید سفارش توسط مدیریت.
- 👨‍💻 **پنل مدیریت پیشرفته در ربات**: تایید یا رد سفارشات، تعریف و مدیریت پلن‌های حجم/زمان، و مدیریت کاربران.
- 🎫 **پشتیبانی و تیکتینگ**: سیستم یکپارچه ارسال پیام و پشتیبانی میان ادمین و کاربران.
- ⏰ **بررسی خودکار**: سیستمی برای بررسی تسک‌های زمانبندی شده.
- 💾 **دیتابیس درایو محلی**: استفاده از `sqlite` (از طریق `sql.js` و `drizzle-orm`) جهت سریع و سبک بودن روند اجرای ربات بدون نیاز به نصب نرم افزار پایگاه داده مجزا.

## 🛠 پیش‌نیازها
- سرور یا سیستمی برای میزبانی (سیستم عامل لینوکس پیشنهاد می‌شود)
- نصب بودن **Docker** و **Docker Compose** (یا Node.js 22 به بالا برای اجرای بدون داکر)
- توکن یک ربات ساخته شده در [BotFather](https://t.me/BotFather)
- پنل 3x-ui نصب شده و آماده به کار همراه با حداقل یک Inbound و یک پنل کاربر (API Token). (جهت سازگاری با نسخه 3.1 پیشنهاد می‌شود)

## ⚙️ متغیرهای محیطی (تنظیمات)
یک فایل `.env` در مسیر اصلی پروژه (در کنار `docker-compose.yml`) ایجاد کنید و مقادیر زیر را با اطلاعات سرور خود تکمیل کنید:

```ini
# توکن ربات که از BotFather دریافت کرده‌اید
BOT_TOKEN=123456789:ABCDefghIJKL_mnopqrSTUVwxyz

# آیدی عددی تلگرام ادمین‌ها (با کاما جدا کنید)
ADMIN_IDS=123456789,987654321

# آدرس پنل 3x-ui شما (بدون اسلش پایانی)
PANEL_BASE_URL=https://panel.example.com:2053

# توکن اتصال به API پنل (می‌توانید در تنظیمات پنل 3x-ui یک توکن جدید تولید کنید)
PANEL_API_TOKEN=your_3xui_api_token

# آیدی Inbound ای که حساب کاربری کانفیگ‌ها در آن ایجاد خواهد شد (مثلاً 1)
PANEL_INBOUND_ID=1

# --- تنظیمات درگاه پرداخت آفلاین (کارت به کارت) ---
PAYMENT_CARD_TITLE=نام و نام خانوادگی دارنده کارت
PAYMENT_CARD_NUMBER=6037123456789012
PAYMENT_NOTES=لطفاً پس از واریز، تصویر رسید خود را با کیفیت واضح در اینجا ارسال نمایید.

# (اختیاری) منطقه زمانی سرور (پیش‌فرض Asia/Tehran)
APP_TZ=Asia/Tehran

# (اختیاری) مسیر ذخیره دیتابیس در کانتینر یا سیستم داخلی
SQLITE_PATH=runtime/data/merkabot.db
```

## 🚀 نصب و راه‌اندازی

### روش اول: استفاده از Docker (پیشنهاد شده)
با استفاده از داکر به راحتی می‌توانید ربات را بدون درگیری با پیشنیازها اجرا کنید. داده‌های دیتابیس درون پوشه `runtime/` ذخیره شده و پس از خاموش شدن ربات پاک نمی‌شوند.

1. سورس کد را به سیستم خود منتقل کنید.
2. فایل `.env` را مطابق با بخش قبلی ایجاد و پر کنید.
3. دستور زیر را در ترمینال وارد کنید:
   ```bash
   docker-compose up -d --build
   ```
   برای مشاهده لاگ‌ها (گزارش وضعيت اجرا) می‌توانید از دستور `docker-compose logs -f` استفاده کنید.

### روش دوم: اجرای دستی و محلی (Node.js)
اگر قصد توسعه یا اجرای ربات بدون داکر را دارید:

1. پیش روی به پوشه پروژه و نصب وابستگی‌ها (پکیج‌ها):
   ```bash
   npm install
   ```
2. بیلد کردن کدهای TypeScript:
   ```bash
   npm run build
   ```
3. اجرای ربات:
   ```bash
   npm start
   ```
*(برای محیط توسعه შეგიძლიათ از `npm run dev` جهت بیلد لحظه‌ای کدها استفاده نمایید.)*

## 📖 نحوه استفاده
پس از استارت شدن بات، نحوه عملکرد آن به شکل زیر است:
1. **تشخیص ادمین**: اگر آیدی عددی تلگرام خود را به درستی در متغیر `ADMIN_IDS` قرار داده باشید، با ارسال دستور `/start` به ربات، علاوه بر منوی کاربری، منوی مدیریت را در کیبورد مشاهده خواهید کرد.
2. **مدیریت پلن‌ها**: به عنوان ادمین، وارد بخش مدیریت شده و از طریق قسمت «مدیریت پلن‌ها»، سرویس‌های اینترنتی خود (حجم و مدت زمان مختلف) را ایجاد نمایید تا کاربران بتوانند آنها را خریداری کنند.
3. **تایید سفارش**: زمانی که کاربر پلن را انتخاب کرده و رسید پرداختی خود را ارسال می‌کند، این رسید به ربات ارسال شده تا توسط ادمین مشاهده شود. ادمین می‌تواند با زدن دکمه تایید، دستور ساخت این سرویس را صادر کند و ربات از طریق اتصال API سرور `3x-ui` حساب را ساخته و کانفیگ را به کاربر تخصیص می‌دهد.
4. **تیکت پشتیبانی**: کاربران می‌توانند با کلیک بر روی گزینه «پشتیبانی»، سوالات و مشکلات خود را ثبت کرده کنند. ادمین مستقیما از طریق ربات می‌تواند مکاتبات را پاسخ دهد.

## 🏗 ساختار فنی پروژه
پروژه با معماری مبتنی بر دامنه (Clean-like) طراحی شده است تا نگهداری آن ساده باشد:
- `src/bot/` : شامل تنظیمات، کیبوردها و دریافت کننده‌های مختص محیط تلگرام (بر پایه فریم‌ورک Telegraf)
- `src/domain/` : منطق اصلی کسب و کار (موجودی‌ها نظیر users, plans, orders, services, support)
- `src/infra/` : سیستم‌های ارتباطی خارجی (Database با Drizzle، لاگر با Winston/Pino، ارتباطات API برای پنل 3x-ui)
